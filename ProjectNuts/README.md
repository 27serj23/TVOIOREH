# 🌰 Твой орех — интернет-магазин свежих орехов

Учебный проект на Django 5 с использованием Jinja2 и Bootstrap 5.  
Полноценный сайт для заказа орехов, включающий регистрацию, каталог с поиском, корзину, оформление заказа и личный кабинет.

## 🚀 Функциональность
- 🔐 Регистрация и авторизация пользователей (с телефоном и адресом)
- 🛍️ Каталог товаров с поиском по названию
- 🛒 Корзина (добавление, изменение количества, удаление)
- 📦 Оформление заказа с сохранением в БД и очисткой корзины
- 👤 Личный кабинет с историей заказов
- ❌ Удаление отдельных позиций из заказа (только для статуса «В обработке»)
- 🛠️ Административная панель Django для управления товарами и заказами
- 🎨 Адаптивный дизайн в ореховых тонах с анимациями
- 🧪 21 юнит‑тест, покрывающий ключевые компоненты

## 🧱 Стек технологий
- **Backend:** Python 3.12, Django 5.0
- **Шаблонизатор:** Jinja2 (с кастомным окружением)
- **Фронтенд:** Bootstrap 5, HTML5, CSS3, иконки Bootstrap Icons
- **База данных:** SQLite (легко заменить на PostgreSQL)
- **Тестирование:** Django TestCase (21 тест)
